# Lightsaber Musical Score Creation

基于 Qt5 的 Beat Saber（节奏光剑）曲谱编辑器项目。

## 项目状态

当前处于需求澄清与架构设计阶段，尚未开始软件实现。2026-10-01，用户选择以 Qt5 为界面框架；此前交接文档中的 Electron 方案为历史建议。

## 已确认的目标

- 在 Windows 10/11 上解压即用、离线运行，使用者无需自行安装 Python。
- 导入歌曲并创建新谱；打开和修改从 BeatSaver 下载的现有曲谱包。
- 手动设置音符的时间、位置、颜色及切割方向。
- 提供自动制谱，并探索音乐情绪对段落编排的影响。
- 编辑现有曲谱时保留未修改的数据、未知字段、音频和附件。

## 待明确的架构决策

- Qt5 使用 C++ 还是 Python 绑定，以及具体 Qt5 版本、编译工具链。
- 首版的编辑对象、格式兼容和预览范围。
- 2D/3D 编辑界面与音频时间轴的交互。
- 离线分析和自动制谱模块的实现、进程边界及发行包大小。
- 开发阶段、验收样本和交付标准。

在开始实现前，通过 `grilling` 技能逐步访谈并记录这些决策；可以要求每次只问一个问题。
