# Lightsaber Musical Score Creation

基于 Qt5 的 Beat Saber（节奏光剑）曲谱编辑器项目。

## 目录结构

```text
Lightsaber Musical Score Creation/
├── src/
│   ├── app/           # 程序入口、启动和模块组装
│   ├── core/          # 核心源码：曲谱模型、时间轴、编辑规则
│   └── gui/           # Qt 窗口、控件、视图与 .ui 文件
├── resources/         # 图标、图片、样式、翻译与 .qrc 文件
├── docs/              # 需求、架构说明和历史资料
├── tests/             # 测试代码及小型测试数据
├── third_party/       # 第三方库及其许可证
├── scripts/           # 构建、打包与开发辅助脚本
├── samples/
│   └── beatmaps/      # 本地曲谱样本，内容不提交 Git
├── .gitignore
└── README.md
```

后续核心源码放在 **`src/core/`**。窗口和 Qt Designer 的 `.ui` 文件放在 `src/gui/`，`main.cpp` 等入口文件放在 `src/app/`。详细说明见 [工程目录说明](docs/工程目录说明.md)。

## 项目状态

当前已建立源码与资料目录，处于需求澄清与架构设计阶段，尚未开始软件实现。2026-10-01，用户选择以 Qt5 为界面框架；此前交接文档中的 Electron 方案为历史建议。

## 已确认的目标

- 在 Windows 10/11 上解压即用、离线运行，使用者无需自行安装 Python。
- 导入歌曲并创建新谱；打开和修改从 BeatSaver 下载的现有曲谱包。
- 手动设置音符的时间、位置、颜色及切割方向。
- 提供自动制谱，并探索音乐情绪对段落编排的影响。
- 编辑现有曲谱时保留未修改的数据、未知字段、音频和附件。

## 待明确的架构决策
