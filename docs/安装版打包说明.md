# Windows 安装版打包说明

更新日期：2026-10-07。安装版和便携版共用 Release 程序及运行依赖，面向 Windows 64 位；Windows 10 的实际兼容性仍须独立验证。

## 使用与数据目录

安装版使用中文向导，默认只为当前用户安装到 `%LOCALAPPDATA%/Programs/光剑曲谱制作/`，不要求管理员权限。提供开始菜单启动与卸载入口，桌面快捷方式可选。已有版本使用固定应用标识更新；安装、升级和卸载前须自行保存并关闭所有运行中的程序实例，不自动关闭未保存工程。

安装目录中的 `installed-mode.ini` 使用固定内容：

```ini
[Deployment]
Mode=Installed
```

仅程序旁有效的普通标记文件启用安装模式，默认工程位置为用户文档中的 `光剑曲谱制作/工程/<歌名>/project.lmsc`，文档目录不可写时报告失败。便携版没有该标记，继续优先使用程序旁 `projects/`，不可写时回退文档目录；源码开发继续使用仓库根的 `projects/`。

设置和日志使用当前用户的配置、应用数据目录。升级和卸载仅处理安装时登记的程序文件、快捷方式与卸载信息，保留工程、歌曲、资源、恢复快照和用户设置，不递归清空整个安装目录。从便携版切换时可直接打开原工程；如需移动，须移动整个工程目录，不自动迁移或删除用户文件。

## 构建安装包

1. 使用既有 Qt 5.12.12 / MinGW 7.3 工具链完成 Release 构建与相关回归。
2. 运行 `scripts/package-portable.ps1`，得到新的完整便携目录。
3. 准备 [Inno Setup](https://jrsoftware.org/isdl.php) 6.7.3 或更新版本，将 `ISCC.exe` 路径传给打包脚本：

```powershell
./scripts/package-installer.ps1 `
  -PortableDirectory 'dist/光剑曲谱制作-本次打包目录' `
  -CompilerPath 'C:/Program Files (x86)/Inno Setup 6/ISCC.exe'
```

脚本严格读取 `package-manifest.json`，检查版本、必需运行库、每项文件大小与 SHA256；拒绝越界路径、链接、重复条目、允许名单之外的文件及未登记文件。使用过的便携目录如果出现工程或设置，必须重新打包，不会从运行目录直接递归收集文件。

每次在 `dist/installers/` 下建立新的版本目录，保留独立 staging、明确的文件清单、安装标记、编译脚本、参数、日志、原文许可及输出 SHA256，不覆盖旧产物。Qt、FFmpeg、WPD 和本地模型调用脚本随包携带；用户歌曲、工程、设备数据、Python 环境与模型权重不随包发布。项目 GPL 与第三方许可原文保留。

`scripts/installer.iss` 固定应用标识和每用户安装模式，以便后续升级。修改默认目录、标识、文件清单或卸载策略后，须重新检查旧版升级和用户数据保留；不能加入递归删除工程目录的卸载规则。

## 发行检查

发布前分别检查完整便携目录和安装后的程序：无开发环境路径启动、合成歌曲导入、音频、编辑、撤销重做、保存、导出与重新打开。检查正常安装、重复安装、运行期间安装和卸载阻断、卸载后用户数据保留；核对快捷方式、卸载登记、版本和文件哈希。

Release 同时提供安装 EXE、便携 ZIP 与 `SHA256SUMS.txt`，源码使用同一发布标签。构建产物和编译器只留本机，不进入 Git 历史。Windows 桌面验证、Windows 10 兼容性和头显实际游玩分别记录。
