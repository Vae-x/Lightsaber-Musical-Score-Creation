# 光剑曲谱制作使用说明

更新日期：2026-10-03，适用于 v0.4.0。此版本包含 AI 整曲生成、进度续跑、诊断日志、分类导入与设备导出；旧 v0.3.0 下载包保留原发布内容。此前 v0.2.0 的测试记录见更新说明。用户已确认导出歌曲在星穹绿洲和光之乐团中可以工作，同时反馈开头约 1 秒物件不显示；新增开场缓冲、AI 曲谱手感与 Windows 10 兼容仍须分别验证。详细证据见 [首版需求与架构](首版需求与架构.md)。

2026-10-04 源码开发版新增“本地快速制谱”，作为“AI 分析与制谱”的默认生成方式，并新增头显歌曲删除和新版灯光、静态颜色物件编辑修复。已发布 v0.4.0 便携包保留原内容。开发版操作差异如下，尚未发布的新功能不代表此前下载包已包含。

## 本地快速制谱（源码开发版）

1. 新歌解码完成后，先在编辑页确认 BPM 与第一拍，再进入“AI 分析与制谱”。生成方式默认“本地快速制谱”，无需配置模型、登录账号、训练模型或安装独立显卡。
2. 可先点击“分析音乐”，查看起音、音乐活动和重复段提示；已有歌曲也可分析。选择难度和允许的物件类型后，点击“生成候选谱”。程序在后台选择音乐起音并搜索动作组合，原工程不改变。
3. 完成后试听时间轴和三维预览；点击应用才添加或替换目标难度，其他难度保留，可以撤销和重做。保存工程及导出仍使用原流程。
4. 本地任务可取消；重新生成会重新编排，音源、时间参数与拍格一致时复用本次运行的分析缓存。切歌、改谱、改时间参数、生成选项或切换生成方式会让旧候选失效。修改模型连接、密钥、代理等设置不影响本地任务和候选。
5. 需要使用原有模型方案时，将生成方式改为“大语言模型制谱”，再配置连接。下文的模型超时、返修、网络恢复和手动续跑只适用于这种方式。

本地算法仅使用检测到的起音，不为凑密度补块；音乐证据不足或动作无法衔接时会减块并提示。只勾选炸弹或墙时，可生成对应避障候选，合适位置不足会减少或停止生成。固定动作模式尚须在两款游戏分别验收；电脑校验不等于已经验证游玩手感。

本地动作包含上下层、内外列和斜切组合，按难度限制摆幅与变化频率。旧开发版已生成的谱不会自动改变；使用新版在原新歌工程中重新生成并预览后，才能应用新的格位与方向。

## 启动与文件

从 [v0.4.0 Release](https://github.com/Vae-x/Lightsaber-Musical-Score-Creation/releases/tag/v0.4.0) 下载完整 Windows 便携包并解压，在 Windows 64 位上双击 **`LightsaberMusicalScoreCreation.exe`**。同目录需要 Qt 运行库、声音/平台插件、`tools/ffmpeg/` 音频工具和 `tools/mtp/` 设备读取脚本及 64 位 WPD helper（使用系统 .NET Framework）；保留这些文件的相对位置。基础编辑与音频转换无需安装 Python、Qt 或 FFmpeg，可离线运行；AI 模型读取和账号授权需要网络，Codex 账号方式还需本机安装官方 Codex CLI。本机打包产物保存在 `dist/`，不随源码仓库提交。

**编辑工程**用于保存继续制作所需的资源与编辑状态；**导出的歌曲文件夹**用于复制到头显。导出请选择一个新的电脑目录，保留原始歌曲与工程，之后仍可继续编辑。

## 主题、AI、网络与关于

v0.4.0 包含以下设置与 AI 功能。设置和 AI 识别直接集成在主窗口，通过左侧导航切换，不另开设置窗口。导航依次是“曲谱编辑、AI 分析与制谱、外观、大语言模型、网络、关于”，账号授权位于大语言模型子菜单。菜单“设置 → 外观设置”或 `Ctrl+,` 直接切换到外观页。

当前版本的“账号授权”位于“大语言模型”子菜单。导航展开时选中“大语言模型”显示账号入口，点击右侧箭头或使用左右方向键折叠、展开；导航收起时点击模型图标或按右方向键打开弹出子菜单。设置草稿和当前歌曲在切换时保留。

左侧导航默认收起，仅显示图标。点击三横线按钮可展开文字，也可再次收起；悬停图标可查看名称，上下方向键可切换页面。展开、收起和切换页面都会保留当前曲谱、选中物件、播放位置及未应用的设置输入。返回“曲谱编辑”可继续原来的工作，导入、音频处理、编辑、保存和导出功能沿用已有流程。右侧设置按卡片分组，小窗口可滚动查看，保存与取消按钮固定在底部。

所有设置页共用三种操作：“应用”保存并留在当前页；“保存并返回”保存后回到曲谱编辑；“取消并返回”恢复最近成功保存的全部设置与主题，再回到曲谱编辑。单纯通过导航离开设置页会保留草稿，不会自动保存。

- **AI 分析与制谱**：歌曲解码就绪后可分析音乐。新建歌曲可在开始前选择五档难度，并勾选方向方块、无方向方块、炸弹和墙，默认只生成方向方块。点击生成后，程序提取本地音乐特征，由所选模型编排整曲；完成后可试听候选谱。点击应用会添加目标难度；目标已经存在时仅替换该谱，其他难度保留。初次完全空白的谱可直接复用为第一个生成难度。已有的本地节拍估计仍在曲谱编辑中使用。
- **外观**：选择浅色、深色或跟随系统，编辑面板与轨道预览一起切换。选择时立即预览；应用或保存后保留主题，取消恢复最近成功保存的主题。
- **大语言模型 / API Key**：选择 DeepSeek、Kimi、MiMo、OpenAI、通义千问或自定义服务。预设自动填入 API 地址，填入对应密钥后离开输入框会自动获取模型；也可点击“获取模型 / 检查连接”。选定模型后保存。读取失败时显示原因，并允许手动输入模型名。地址须包含服务要求的路径（通常为 `/v1`）；本机网关支持 loopback HTTP 地址，远程服务使用 HTTPS。
- **大语言模型 / Codex**：将使用方式切换为 Codex / ChatGPT 账号授权，再进入“大语言模型 → 账号授权”。本机有官方 Codex CLI 时自动查找，也可手动选择程序。点击“检查授权”复用已有登录，或点击“使用 ChatGPT 登录”在浏览器完成官方授权，随后获取账号模型并选择。授权和凭据续期由 Codex 管理。
- **网络**：默认“自动（系统代理）”，API 请求使用系统代理，Codex 沿用自身默认网络配置。选择“手动（HTTP 代理）”后填写 IP 或域名与端口，例如 `127.0.0.1`、`7890`；地址不带协议或端口。手动配置用于 API 请求和本程序启动的 Codex 账号服务，本机服务保持直连；切换后可重新获取模型检查连接。点击“应用”或“保存并返回”后保留配置；“取消并返回”恢复最近成功保存的配置。浏览器沿用自己的网络设置。
- **关于**：查看当前版本、作者 Vae-x 与许可，通过“打开项目主页”在默认浏览器打开 GitHub 项目。“查看 GPLv3 许可”在本页展开官方英文全文，可滚动阅读或收起；帮助菜单的“关于光剑曲谱制作”也进入本页。
- 各提供商的地址、密钥和模型独立保存。Windows API Key 由当前账户的 DPAPI 加密；应用设置保存在用户配置目录中，歌曲工程与游戏导出包不包含这些设置。账号登录保存在 Codex 自己的凭据存储中；取消设置不会退出已有账号。

基础编辑和音频转换仍可离线运行。AI 模型读取、分析及制谱需要网络，Codex 账号方式需要本机官方 Codex CLI，生成通道按 0.147.0 协议实现。模型只接收时间锚点、音乐特征与动作上下文；配置连接本身不会发起生成。生成失败或取消时原谱保持原状，只有完整通过硬校验的候选谱可应用。具体流程见 [AI 设置与自动制谱方案](AI设置与自动制谱方案.md)。

重复段的主题一致性作为质量目标，动作安全、有效起音、跨段衔接及难度上限仍必须通过。主题返修耗尽后，若存在通过硬校验的候选，程序保留较好的版本继续生成，并显示“候选谱已生成，部分乐句建议试听”。结果页和预览列出对应乐句、时间范围与差异，试听确认后再应用。节奏、音符数量和安全位置可以适应当前音乐，不要求逐块复制参考段；没有合格候选时仍显示失败。

当前版本会在切换页面后继续 AI 任务，返回时保留进度和分析；完成的候选谱可用“查看候选谱”反复打开。先分析再生成时，相同音源、时间参数、难度、类型和模型可沿用分析规划。网络、超时或暂时服务故障会自动恢复，同一规划或乐句最多两次、整任务最多十次，与校验返修次数分别计算；等待恢复时可停止。只有自动恢复耗尽、需要修改配置或校验失败时才暂停或终止。可续跑时，“继续生成”保留已通过乐句，仅重发未完成部分；手动继续不重置整任务自动恢复次数。“重新生成”从头编排。关闭程序后不保留任务；切歌、改谱、时间参数、生成选项或模型后需要重新生成。

“大语言模型 → 最大输出额度（token）”默认自动。官方 DeepSeek 地址的 `deepseek-flash` / `deepseek-v4-pro` 从 **65536** 起步，截断后可自动提高至 **131072**，后续乐句沿用；保留模型的默认思考。未知接口自动模式不指定额度，截断时需填写服务支持的上限。手动范围 **1024–131072**，DeepSeek 初始额度取 65536 与设置值中的较小者，其他接口取 8192 与设置值中的较小者，截断后翻倍至上限。自动次数耗尽后，手动继续也会在仍有余量时提高截断请求的额度；已达上限时需修改设置或模型。提高的是允许额度，实际用量取决于响应；思考可能计入额度，自动重试也可能产生额外用量。CX 沿用 CLI 原生额度，正在内部重连时程序继续等待。

当前版本网络页新增“直连（不使用代理）”和“检查代理端口”。端口检查只确认 HTTP 代理响应，实际服务仍须获取模型或推理验证。分析与制谱的单次模型请求默认 **10 分钟**，可调为 **1–30 分钟**；等待时显示连接阶段和耗时，连续生成达到 45 分钟时暂停并保留进度。

排查失败时，在 AI 页点击“查看本次日志”，或在“关于 → 查看 / 导出日志”查看所有记录；“打开日志目录”可定位文件。默认记录最近七天、最多五个 5 MiB 文件，可关闭记录。日志包含耗时、失败阶段、代理模式、错误码、恢复次数、退避时间、输出额度和用量、思考用量及最终文本字节数；服务未报告的数值为 `-1`，API 未指定额度时请求记录为 `0`。主题记录还包含参考段、置信度、音符数量、各项差异与处理结果，不含密钥、账号内容、歌曲路径、候选全文、提示词或思考正文。导出需选择新的文件名；下次出现问题时，可提供该任务日志帮助区分具体原因。

## 从 MP3 或 MP4 开始

1. 点击“新歌 · MP3 / MP4”，打开 MP3 或 MP4。在“创建新歌 · 音轨与裁剪”中填写歌曲名、作者 / 歌手、谱师，选择封面（可选）。MP4 仅提取声音；“提取音轨”可选择需要的音轨，没有音轨时会明确提示。
2. 输入“裁剪起点”“裁剪终点”。默认保留整首；用“试听所选片段”“停止试听”检查范围，确认后点击“转换并创建”。裁剪后时间零点就是片段起点，不会修改原文件。
3. 等待后台转换、PCM 解码与波形准备。转换为 Ogg/Vorbis，取消任务不会提交未完成的最终音频文件。
4. 在创建弹窗中选择简单 Easy、普通 Normal、困难 Hard、专家 Expert 或专家+ ExpertPlus，默认 Expert；只创建一张 **v2.2 / Standard** 空白谱。创建后也可在左侧“新歌难度”调整，已有音符保留；当前版本的手动难度调整也作为单独一步撤销、重做。未选封面时生成默认封面，选定图片会居中裁成正方形。上述为通用文件标识，两游戏界面档位的准确对应仍需分别核验。
5. 自动估拍后勾选“节拍器”试听，检查拍线是否持续对齐重拍。必要时在“节拍校准”手动改“BPM”“第一拍时间”，点击“应用校准”；也可点击“重新估计节拍”或检查半速/倍速。自动估计不准仍能继续手动制作。
6. 在时间轴定位到需要的拍点，选择物件种类、颜色、切割方向，再在 4×3 网格放置；用属性区细调时间、位置和普通墙尺寸。
7. 保存编辑工程，检查“导出开场缓冲”后导出歌曲文件夹，再复制到所用游戏的目录进行头显验收。

新歌导出时，每个难度分别命名为 `Easy.dat`、`Normal.dat`、`Hard.dat`、`Expert.dat` 或 `ExpertPlus.dat`，`Info.dat` 引用同步对应。当前版本会保存和导出全部已有难度，开场缓冲同步后移每张谱并只给音频添加一次静音。已有歌曲继续保留原谱面文件名。

当前版本的新歌可在左侧难度列表切换已生成谱面；“新歌难度”用于修改当前谱的标识，选择已存在的名称会切换到该谱。新歌撤销、重做按整首歌的操作顺序执行，并切换到相关谱面；撤销新增难度会移除该谱并回到之前选中的难度。已有导入歌曲继续按当前难度撤销。保存工程及恢复快照会保留所有难度，不改原始资源快照。

左侧“导出开场缓冲”默认 **2 秒**，可调整为 **0～10 秒**；**0** 关闭缓冲。它只作用于新歌的游戏导出：音频前增加相应静音，方块、炸弹和墙的时间同步后移，原工程的音频、波形和编辑时间不变。例如原来 0.2 秒的方块，在 2 秒缓冲的导出歌曲中于 2.2 秒出现，并与后移后的声音保持对齐。已有谱不添加缓冲。

这个选项用于尝试规避游戏开头约 1 秒物件不显示的问题；开头物件可能缺少生成所需的预滚时间，具体原因尚未由游戏端确认。缓冲效果需要在星穹绿洲与光之乐团中分别复测，不能仅凭电脑导出校验认定已经修复。

“重新裁剪来源 · 新建空白谱”沿用工程保存的原媒体、音轨和范围，重新转换后创建**另一张空白新谱**。已有音符不随裁剪自动迁移；操作前会说明该行为，请先保存当前工程。原媒体和裁剪记录用于工程继续编辑，导出给游戏的歌曲目录仅使用当前转换音频。

## 编辑已有谱

1. 点击“导入歌曲”（`Ctrl+O`），在电脑页浏览、选择或拖入含 `Info.dat` 的歌曲目录或 ZIP，软件自动识别来源类型。直接读取头显歌曲的方法见下一节。程序建立独立资源快照，导入不覆盖原曲谱。继续已有工程时用“打开编辑工程”选择 `.lmsc` 文件。
2. 选择要编辑的一张难度。已有其他难度和玩法保留；首版基础编辑范围是 Standard 双手玩法的 v2/v3 谱面。
3. 查看导入提示与具体字段的保护原因。布尔型编辑器书签设置 `customData.bookmarksUseOfficialBpmEvents` 不影响游戏时间，正常保留并允许基础编辑；异常类型或真正未知的时间扩展仍只读。另存工程保留原数据，不会解除这些保护；无法解释的关联或特殊玩法也继续保护。
4. 选择普通方块、炸弹和墙执行基础修改。多选命令同样受核心保护检查；关联弧线/链条或模组特效的方块可能无法修改、删除、镜像或复制粘贴。
5. 保存工程并导出到新目录。已有音频保持原资源；`.egg/.ogg` 差异按实际文件与唯一候选识别，不会自动统一改名或重新压缩。

新版 v2 谱面的普通灯光事件按版本识别，不再误判为旧变速而锁住整张谱。只有静态颜色扩展的基础物件可编辑，颜色随保存、复制粘贴和导出保留；动画、轨道、扩展坐标或弧线关联仍受保护。已保存的工程使用修复版重新打开即可按当前规则判断，无需删除工程或重新制谱。

已有曲谱的 BPM、第一拍偏移和变速数据保持原样，界面不允许手动改动这些参数。

## 从 PICO 头显读取已有歌曲

1. 通过 USB 连接 PICO Neo 3，解锁头显并允许 USB 文件传输。
2. 点击“导入歌曲”，打开“PICO 头显”页。按设备、游戏、分类文件夹和歌曲展开树，用搜索框过滤歌曲并保留其上级分类。同名歌曲按完整位置区分；空游戏根也保留展示。连接后没有列表时刷新并检查授权与目录。
3. 展开分类并选中歌曲叶节点，点击“导入选中歌曲”；设备、游戏和分类节点不能作为歌曲导入。等待复制和文件检查完成，再选择难度进行编辑。有些歌曲目录名以 `.zip` 结尾，它们仍可作为头显歌曲目录导入。

扫描最多检查 20 层、4000 首歌曲和 10000 个目录。找到 `Info.dat` 后不再把歌曲资源子目录当作分类继续找歌；超限会明确停止并提示未完成完整扫描，不把部分结果显示成完整歌单。扫描和复制可取消，断连后重新授权并刷新。

头显歌曲或分类目录名可含 `|` 等 Android 允许的字符，浏览和导入保留其原名，无需在头显改名。歌曲复制到软件创建的独立电脑目录；实际音频、谱面等资源文件名仍须符合 Windows 文件名规则，不符合时提示具体资源并停止复制。

4. 用“保存工程”保留到电脑的独立工程，随后按普通编辑流程操作。读取失败或中途断开时按提示重试；未完成的复制不会作为可编辑歌曲打开。

两处完整路径：

```text
星穹绿洲：此电脑\Pico Neo 3\内部共享存储空间\SoulTopia\BeatNote\Custom
光之乐团：此电脑\Pico Neo 3\内部共享存储空间\Android\data\com.StarRiverVR.LightBand\files\CustomMusic
```

这一入口只读取头显并复制到电脑临时缓存，不写回头显。电脑里的编辑工程与头显原歌曲分别保存；歌曲导出先在电脑完成，可手动复制或按下一节直接新增到所选游戏。Windows 文件选择器中的“此电脑”设备位置并非普通磁盘路径，应使用上述“PICO 头显”页导入。

## 删除头显歌曲

在“导入歌曲 → PICO 头显”中选中一首歌曲，点击“删除头显歌曲”。软件先读取并核对该歌曲，确认窗口显示设备、游戏、完整位置和待删除文件数；确认删除后才开始执行，默认选择取消。设备、游戏根和分类文件夹不能作为删除目标。

删除会移除头显中的所选歌曲目录及其资源，不能撤销；电脑上已经保存的工程保留，成绩、收藏和游戏配置不修改。确认后如果目标内容发生变化，软件停止操作并要求重新刷新。执行中关闭窗口不会取消已完成的删除；断连或失败可能只删掉部分资源，提示后需重新连接并刷新检查。连接设备、导入或导出不会自动删除歌曲。

## 时间轴、试听与选择

- 时间轴和网格使用同一拍数/秒数换算。节拍吸附决定放块和移动时的对齐精度。
- 时间轴滚轮缩放，Shift＋滚轮或右键/中键拖动浏览其他片段；点击空白时间位置或双击定位播放头。
- 点击物件选择，Ctrl 配合点击进行多选，空白处拖动框选；受保护对象显示锁和原因。
- 播放、暂停与定位按实际音频时钟同步轨道视图。慢放保持音高，第一次切换速度需要等待后台缓存准备。
- Shift＋左键拖动选择循环片段，然后启用循环，便于反复修改一段。节拍器用于校准，已有变速谱以识别出的分段时间模型为准。
- 轨道视图显示普通方块、炸弹与墙，可用于观察基础砍击方向和布局。弧线、链条、灯光与模组数据保留，但暂不专属绘制或模拟完整游戏效果。

## 保存与恢复

先点“保存工程”建立工程，默认建议 `projects/<歌名>/project.lmsc`；同名工程目录已存在时使用带编号的新目录，保存对话框中仍可更改位置和文件名。源码开发使用仓库根的 `projects/`，便携运行使用程序旁的 `projects/`；应用目录无写权限时回退到用户文档中的 `光剑曲谱制作/工程/`。

旁边的 `assets-*` 是原始资源快照，`source-*` 保存新歌原媒体，`autosave.lmsc` 是自动保存恢复快照；它们需要和工程入口一起保留、移动。每份工程放在独立目录，不要只带走 `.lmsc` 文件。

首次保存后，每 30 秒自动保存未保存的改动；用“打开编辑工程”重新打开 `.lmsc` 时，根据提示选择是否恢复快照。

编辑操作支持撤销重做；批量修改如果碰到受保护内容，会报告原因，不应默默只改一部分。导出与工程保存分别进行，导出的歌曲目录不包含游戏成绩或收藏配置。

工程清单原子写入，电脑歌曲目录也使用暂存后提交。保存与电脑导出任务开始后等待完成；设备上传可在进度窗口取消，音频转换、解码等任务可通过“取消任务”取消。

## 歌曲导出与 PICO 传输

1. 点击“导出歌曲”，选择电脑保存目录和导出方式。电脑输出为 `所选目录/光剑曲谱制作/歌曲名-by光剑曲谱/`；同名目录或文件占用时追加 `-2`、`-3`，不覆盖。完成后用“打开歌曲目录”直接找到完整歌曲。
2. 手动方式复制整个导出的歌曲目录到对应游戏根目录下的“光剑曲谱制作”分类。工程的 `assets-*` 是原始资源快照，手动复制它不会包含后续编辑；请使用正式导出目录。
3. 连接、解锁 PICO 并允许 USB 文件传输后，也可选择直接导出及目标游戏。程序先保留完整电脑副本，再只在目标游戏既有歌曲根目录的“光剑曲谱制作”下新增独立歌曲目录。连接设备不会自动上传。
4. 直接上传逐文件回读校验 SHA256，最后上传 `Info.dat` 并检查引用。不要在传输中拔线。取消或失败时保留电脑副本，窗口会提示可能残留的设备新目录；不自动删除、不覆盖原曲目，不修改成绩、收藏或配置。
5. 游戏目录不存在或无写入权限时停止设备导出，仍可使用电脑副本手动复制；不会自动创建游戏根目录。

两款游戏既有歌曲根目录分别为：

```text
星穹绿洲：SoulTopia/BeatNote/Custom
光之乐团：Android/data/com.StarRiverVR.LightBand/files/CustomMusic
```

在所选游戏根目录下新增 `光剑曲谱制作/歌曲名-by光剑曲谱/`。光之乐团分类按用户反馈提供；星穹绿洲分类读取没有可靠公开说明，仍须在游戏内确认，不能将文件传输成功当作游戏已能识别。

在两个游戏分别检查歌曲显示、声音、难度、开头物件及动作手感。新歌默认 2 秒缓冲，先静音再播放原音乐，工程试听时间保持原样；缓冲效果与 AI 生成的游玩体验须分别实测。此前导出歌曲在两游戏可用的反馈不等于本次新增功能已通过实机验证。APK 留在后续阶段。

## 开发者补充

源码通过根目录或 `src/` 的 CMake 入口构建；当前使用 Qt 5.12.12 / MinGW 7.3。新构建使用 `build/debug/` 或 `build/release/`，旧构建与核验产物保留于 `build/archive/`；原 CLion `src/cmake-build-debug/` 保持原位。首次准备音频依赖运行 `scripts/setup-audio-tools.ps1`，该脚本下载固定 Windows x64 LGPL shared 构建并检查 SHA256 与 Vorbis 编码器。依赖版本、许可和公开发行前需要整理的材料见 [音频工具说明](../third_party/ffmpeg/README.md)。

Release 编译完成后，`scripts/package-portable.ps1` 在 `dist/` 创建新的便携目录，携带 Qt 运行库、声音插件、FFmpeg/ffprobe、MTP 读取脚本、64 位 WPD 传输工具、项目 GPL 与第三方许可说明；完整目录另压缩为 Windows ZIP。只有开发者准备依赖或重新打包需要这些脚本；普通使用者直接解压完整便携包。

`tests/GenerateAudioFixtures.ps1` 生成自制 120 BPM 的 MP3、双音轨 MP4 和无音轨 MP4，生成数据放在忽略的构建目录，不包含用户歌曲。`AudioServiceTest` 使用这些文件验证音频流程；实际播放测试需要有效的 Windows 声音设备。
