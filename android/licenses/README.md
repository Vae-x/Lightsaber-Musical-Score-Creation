# Android 第三方许可

本项目采用 GNU GPL 第 3 版，原文见 `PROJECT-GPL3.txt`。Android 预览包动态使用 Qt5、FFmpegKit 音频库、OpenSSL 及其依赖；各自原始许可证和对应源码链接保存于 `qt/`、`android-ffmpeg/`、`openssl/`。

FFmpegKit 制品固定为 `dev.ffmpegkit-maintained:ffmpeg-kit-audio:6.0.4`，Qt 为 5.15.2，OpenSSL 为 KDAB 固定提交的 1.1 系列二进制。构建和下载校验脚本、应用对应源码见：

https://github.com/Vae-x/Lightsaber-Musical-Score-Creation

预览版本验证范围与限制见仓库 `docs/Android打包与使用说明.md`。第三方许可条款保持原文。
